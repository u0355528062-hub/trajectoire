# Politique de confidentialité — TRAJECTOIRE

## Ce qui est collecté

Des statistiques d'usage **strictement anonymes** :

- un jeton aléatoire généré par votre navigateur, sans lien avec votre identité ;
- la version du jeu ;
- la durée de vos sessions ;
- des données de progression : poste choisi, carte tirée, division, générale,
  saisons jouées, matchs, buts, passes.

## Ce qui n'est **jamais** collecté

- votre nom, celui de votre joueur, ou tout texte que vous saisissez ;
- votre adresse IP (elle n'est ni journalisée ni stockée) ;
- votre localisation ;
- aucun identifiant d'appareil, aucun cookie publicitaire ;
- aucune donnée n'est transmise à un tiers, ni vendue.

## Pourquoi

Uniquement pour équilibrer le jeu : savoir où les joueurs abandonnent,
quels postes sont choisis, si la progression est trop lente ou trop rapide.

## Base légale et durée

Statistiques anonymes, sans identification possible d'une personne.
Les données sont supprimées automatiquement après **13 mois**.

## Vos droits

Le suivi est **désactivable à tout moment** depuis le menu du jeu.
Effacer les données du site supprime définitivement votre jeton :
plus aucun lien n'existe alors entre vous et les statistiques passées.
